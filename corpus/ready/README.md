# corpus/ready/

**Everything in this directory is safe to use as training, few-shot or retrieval data.**

Each file here is openly licensed (public domain or CC0), trimmed of front and back matter, and was reviewed by a human before `scripts/dev/corpus/corpus.py promote` copied it in. Files are laid out as `<form>/<id>.txt`.

Do not edit these files by hand, and do not copy anything in from `raw/` or `draft/`. To change a text, change its row in `../sources.csv` and re-run the pipeline. See `../README.md`.
