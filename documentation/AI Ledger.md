# AI ledger

Scope: **remote AI only**, meaning Claude work on this project (setup, code, debugging).
Local AI that runs on the Pi (whisper.cpp, the local LLM, the embedding gate) is not logged here.

Token counts come from Claude Code's `/cost` or `/usage` at the end of the day. Don't estimate them from memory.

Claude's entries are signed (Claude). Claude cannot run `/cost`, so their counts are summed from the usage recorded in the session transcript (each API request once): *effective* = uncached input + output + cache writes, *raw* = that plus cache reads. Names in them are the lexicon's current ones. Replace the figures with `/cost` numbers if you prefer.
